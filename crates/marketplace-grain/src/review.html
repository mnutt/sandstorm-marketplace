Settings

Connect Keybase

Connect this marketplace to Keybase to look up authors using their verified PGP fingerprints. Connect once per marketplace; the connection is saved for future lookups. You can reconnect if access is revoked or stops working.

Notifications

Email an administrator or distribution list when an author requests review or publication. Leave blank to disable. Changing the address discards queued messages for the previous address; a message already being sent may still arrive.

Key replacements

Replace a lost or compromised signing key while keeping the original app ID. Sandstorm servers and packaging tools must also know the replacement before packages signed with it can reliably upgrade existing installations.

Existing mappings are permanent. To rotate again, add a rule from the current replacement key to the new key. Saving revalidates affected packages; packages that fail validation are removed from the public site but retained in review history.
